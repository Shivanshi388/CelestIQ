# Demo Scenarios

This project includes demo scenarios used for presentations and testing. If you do not have the `demo/` folder in your local copy, create it and add `scenario.json` and `sample_alerts.json` as provided in the upstream repository or create simple examples for testing the frontend UI.

Typical demo files
- `scenario.json` — a JSON scenario describing objects and predicted conjunctions.
- `sample_alerts.json` — example alert messages for the dashboard.

Usage
- Serve the frontend locally and load demo files via the UI or by placing them into the expected `data/` folder used by the frontend mock services.
