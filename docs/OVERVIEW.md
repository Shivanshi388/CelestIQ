# Overview

CelestIQ is a browser-first orbital operations interface prototype. The current product demonstrates authentication flows, a dashboard, alert review, manoeuvre comparison, and a textured Three.js orbit scene using mock data. The Python analytics and SQL layers are planned.

Start with the [documentation hub](README.md), then follow [Getting Started](Detailed_docs/GETTING_STARTED.md) for local setup and [Architecture](ARCHITECTURE.md) for the implementation boundary.
